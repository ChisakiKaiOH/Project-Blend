# Lezione 1 — Soluzioni commentate (leggi solo dopo aver risposto)

1. **Z**, colore **blu**. X è rosso, Y è verde.
2. L'oggetto *attivo* è uno solo (contorno arancione chiaro) e le Properties mostrano i suoi dati; gli altri *selezionati* sono arancione scuro. Le trasformazioni agiscono su tutti i selezionati.
3. Seleziona l'oggetto, mouse sulla viewport, `G`, `Y`, `-2`, `Enter`.
4. In ortografica gli oggetti lontani non rimpiccioliscono, quindi le distanze si confrontano correttamente.
5. Attiva `Edit → Preferences → Input → Keyboard → Emulate Numpad` oppure usa il Navigation Gizmo e il menu `View → Viewpoint`.
6. L'oggetto torna alla posizione di partenza: l'operazione è annullata.
7. Se sbagli, puoi tornare a una versione precedente intatta; un solo file sovrascritto non lo permette.
